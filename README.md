Entry for the make.fun bounty "The plan make.fun will carry out in public".

`main.py` writes a single 1-280 character plan (an agent-executable 30-day
path from $100 to more money) to `entry.txt`. It is deterministic, uses only
the Python standard library, and makes no network calls.

## Run

    python3 main.py

Output goes to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set,
otherwise to `./output/entry.txt`. The directory is created if missing.

The script prints the plan text and its character count, and exits non-zero if
the text falls outside 1..280 Unicode code points.
